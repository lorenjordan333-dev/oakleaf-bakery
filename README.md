# Oakleaf Bakery

A small storefront page, built so a new DebuggerOS user has something real to point at
during onboarding. Vite + React, deployed to GitHub Pages by the workflow in
`.github/workflows/deploy.yml`.

It is deliberately NOT connected to DebuggerOS: no widget snippet, no project registered,
no GitHub App access. Connecting it is the thing being tested.

There is one planted bug. It is visible the moment the page loads.
